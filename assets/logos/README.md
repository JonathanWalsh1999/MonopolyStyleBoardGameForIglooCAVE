# Company logos

The six parody companies use logos drawn in code. To replace one with your own artwork, upload a PNG here with the matching name:

`amazoom.png`, `costalot.png`, `greggles.png`, `toktik.png`, `primarket.png`, `nandoughs.png`

- Use a square, transparent PNG, at least 1024 px.
- Keep it original: no real company logos.
