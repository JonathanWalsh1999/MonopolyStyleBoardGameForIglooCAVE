# Character images

Drop your monster images here and the game uses them automatically. No code changes needed.

| File name | Required? |
|---|---|
| `gloop-normal.png`, `spike-normal.png`, `zappo-normal.png`, `fuzz-normal.png`, `chomp-normal.png`, `wisp-normal.png` | Yes (one per monster you want to replace) |
| `<name>-happy.png` | Optional: shown after a correct answer |
| `<name>-sad.png` | Optional: shown after a wrong answer |

- Use transparent PNGs, roughly square, at least 1024 px.
- Centre the character so it fills most of the frame, with no background and no text.
- Any monster without an image keeps its built-in drawing.
